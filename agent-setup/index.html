Agent setup

Your agents are already working. This is how they come to work somewhere you can watch. Paste one sentence into any AI coding agent and it sets itself up.

Fetch and execute the appropriate instructions to set me up for The Roving Office from https://therovingoffice.com/agent-setup/prompt.md

That is the whole of it. The agent fetches prompt.md, works out which harness it is running in, mints you an office, installs the right adapter and tells you the URL.

It asks you one question first

Deliberately, and it is the one step the instructions forbid the agent from skipping. Connecting a session transmits what your agent is doing — your repository's host, owner and name, the branch, the working directory, and which tools ran. It does not transmit file contents, your prompts, the agent's replies or command output; redaction happens on your machine before anything is sent.

An office is readable by anyone holding its eight-character keycard. There are no accounts. So the agent shows you that list, waits for a yes, and only then does everything else unattended. Say local only instead and it will set up an office on your own machine, where nothing leaves it at all.

A clone needs no npm install. The app has no runtime dependencies and the connect scripts use Node's built-in modules only, so a shallow clone and one command is the whole of it.

Why a document rather than an installer

An installer has to know every harness in advance, and new ones keep appearing. A document an agent reads can describe five and leave the sixth to the protocol — and the agent is already good at working out which of the five it is. The instructions are plain Markdown at a stable URL, so you can read exactly what you are about to run before you run it. That seemed like the minimum courtesy for a page that asks you to paste a URL into something with shell access.

The idea is Cloudflare's, and it is a good one.

Doing it yourself

Nothing here is magic and none of it needs an agent. Install and run it is five minutes by hand, and connect your agents is the same ground at human pace — including the redaction table, which is the page worth reading before you point a real session at an office you intend to share.
